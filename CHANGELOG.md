# Changelog

## v2.2

- Updated both bundled kernel sources for DS Style v7.5, including animated carousels, side-size options, browser wrapping and defensive file checks.
- Preserved non-destructive project importing, cross-cartridge conversion and the existing artwork layout.
- Aligned the Settings font preview with the current Interface menu.

## v2.1

- Added native bitmap launcher font selection with an accurate project Settings-screen preview.
- Added Spleen 6x12, Tamzen 6x12, Tamzen 6x12 Bold, and GalmuriMono9 font presets.
- Kept launcher spacing, alignment, scrolling, and supported accented characters compatible across every font.
- Preserved selected fonts when importing or converting projects.
- Preserved readable version numbers such as `v7.3` in imported and updated project names.
- Bundled the alternative fonts' open-source licence notices.
- Updated the bundled kernel sources and compatibility information for DS Style v7.4.
- Refreshed the bundled Omega Definitive Edition source with the v7.4 Clean Boot compatibility fix.

## v2.0

- Added an option to use each screen background's upper 19 pixels in place of a separate top-bar image.
- Updated the layout previews to follow the selected top-bar mode.
- Kept existing projects compatible, with separate top-bar images remaining the default.
- Updated the bundled sources and compatibility information for DS Style v7.3.

## v1.9

- Added Import / Convert for bringing older projects onto the current DS Style source.
- Added non-destructive conversion between Original Omega and Omega Definitive Edition projects.
- Preserved supported artwork, colours, sounds, text and layout choices during conversion.
- Prevented Original Omega builds from adding separate Custom Theme or Custom Colour slots that exceed the cartridge's kernel size limit.
- Updated the bundled sources and compatibility information for DS Style v7.2.

## v1.8

- Updated bundled source compatibility for DS Style v7.0.
- Added support for the latest interface settings and launcher text.
- Refreshed included source folders, templates and user guide.

## v1.7

- Improved scaling and window sizing on high-resolution displays and smaller desktops.

## v1.6

- Added customisation for supported interface-element positions.
- Added visual layout editors and previews for supported launcher screens.

## v1.5

- Added support for the original EZ-Flash Omega.
- Added editing for all built-in language options.

## v1.4

- Added new language options and accented-character support.
- Added top-bar text and favourite-heart colour customisation.

## v1.3

- Updated compatibility for DS Style v6.3.
- Added the new SD and NOR screen assets.
- Added the Text tab.

## v1.2

- Added sound customisation.

## v1.1

- Added the Custom theme option.

## v1.0

- Initial release.
